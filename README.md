# TP1 MLOps — Customer Churn Prediction

This project builds a first customer churn prediction model before introducing MLOps tooling. It uses a synthetic dataset, explores and prepares the data, trains and evaluates Random Forest models, and compares three experiments.

## Dataset

`churn_data.csv` contains 500 fictional customers and six columns:

- `age`, `salaire`, `abonnement`, `anciennete`, and `consommation` are the model features.
- `churn` is the binary target. It is set to 1 when `consommation < 30` and `anciennete < 2`; otherwise it is 0.

The dataset is generated by `generate_data.py` with a fixed NumPy random seed.

## Workflow

The `churn_model.ipynb` notebook documents the project steps:

1. Explore the dataset and check its dimensions and missing values.
2. Encode `abonnement` as Basique=0, Standard=1, Premium=2, then create an 80/20 train/test split with `random_state=42`.
3. Train and evaluate a `RandomForestClassifier` using accuracy and a classification report.
4. Compare three experiments on the held-out test set:

| Experiment | Configuration | Accuracy |
|---|---|---:|
| Essai 1 | 100 trees, depth 5, five features | 0.99 |
| Essai 2 | 50 trees, depth 3, five features | 0.99 |
| Essai 3 | 100 trees, depth 5, four features (without `salaire`) | 1.00 |

The notebook records the results and reflection notes. The experiment code saves each new model to `model.pkl`; after the final experiment, that file contains the Essai 3 model. The model file is ignored by Git.

## Setup and run

From PowerShell in the project directory, create and activate a virtual environment, install the dependencies, and register the notebook kernel:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install numpy pandas scikit-learn joblib jupyter ipykernel
python -m ipykernel install --prefix .venv --name tp1-venv --display-name "Python (TP1 venv)"
```

Generate the dataset and open the notebook:

```powershell
python generate_data.py
jupyter notebook churn_model.ipynb
```

Run the notebook cells from top to bottom to reproduce the exploration, data preparation, training, evaluations, and experiments. Running `generate_data.py` recreates `churn_data.csv`; running the Step 6 cells overwrites `model.pkl` with the latest experiment, Essai 3.
